# 🔥 AR Fire Safety Training Simulator

An Augmented Reality (AR) based Study & Training Simulator developed by **Team Karmaxx**. This application provides an interactive learning environment to train users on fire safety procedures using real-time AR simulations.

---

## 📖 About the Project

**AR Fire Safety Training Simulator** is a Unity-based application designed to train individuals on fire safety protocols in a safe and interactive environment. Using Augmented Reality, users can simulate real-world fire hazards, learn how to use fire extinguishers, and understand emergency procedures without any actual risk.

This project is developed as part of the **Karma Organization** initiative to create accessible, immersive educational tools for Android and PC platforms.

---

## ✨ Key Features

- 🕶️ **Augmented Reality (AR) Support** – Realistic fire safety simulations using AR Foundation
- 🧯 **Fire Extinguisher Training** – Learn proper usage of different types of extinguishers
- 🚨 **Fire Hazard Simulation** – Interactive scenarios to practice emergency response
- 📱 **Cross-Platform Support** – Built for Android and PC using Universal Render Pipeline (URP)
- 🎯 **Interactive Training Modules** – Step-by-step guided learning with real-time feedback
- 🎮 **User-Friendly Interface** – Simple and intuitive controls for all age groups
- ⚡ **Optimized Performance** – Mobile-friendly rendering with quality settings
